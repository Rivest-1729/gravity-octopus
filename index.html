05 / Technology Spectrum

技术路线光谱

侵入式 Invasive
皮层内 · 单神经元

开颅手术将微电极阵列植入大脑皮层内部，直接记录单个神经元放电信号。信号空间分辨率极高、信噪比优异，但存在手术风险、免疫排异与长期稳定性挑战。

代表：Neuralink · Blackrock · 脑虎科技 · 阶梯医疗
半侵入式 Semi-invasive
硬膜外 / 硬膜下

微创钻孔将电极放置于脑表面（硬膜外或硬膜下），在开颅创伤与信号质量间取得平衡。微灵医疗WE-LINK-ING、博睿康等走此路线。

代表：微灵医疗 · 博睿康 · 智冉医疗
非侵入式 Non-invasive
头皮 EEG / fNIRS

通过头皮电极采集脑电信号（EEG）或近红外光谱（fNIRS）监测血氧变化。安全、低成本、可消费级，但信号微弱、分辨率有限。占全球企业约80%。

代表：强脑科技 · Emotiv · Kernel
介入式 Endovascular
血管内支架

通过血管介入手术（如颈静脉）将Stentrode支架电极送至大脑皮层表面血管，无需开颅。Synchron是全球先行者，融合了微创血管技术与神经信号采集。

代表：Synchron

08 / Decoding Mathematics

解码的数学——信号、公式与密码

脑机接口的核心是从噪声中提取信号，从信号中解码意图。这既是神经科学问题，也是信息论与计算数学问题——神经元放电序列如同加密的报文，而解码算法就是破解密钥的密码学。

信号解码模型
y(t) = f(x₁(t), x₂(t), ..., xₙ(t)) + ε(t)
神经信号解码的基本框架：n个神经元的放电序列{xᵢ(t)}经非线性映射f解码为运动输出y(t)，ε(t)为噪声。现代BCI用深度学习替代手工设计的f。
泊松点过程编码
P(k; λt) = (λt)ᵏe^(-λt) / k!
神经元放电被建模为非齐次泊松过程，λ为随时间变化的放电率。这是神经编码的数学基石——解码问题本质上是从观测的k次放电反推潜在的λ(t)。
线性判别分析 (LDA)
w = Σ⁻¹(μ₁ - μ₂)
BCI运动想象分类的经典算法：寻找最优投影方向w，使两类信号的类间方差与类内方差之比最大化。EEG信号的二分类（左手/右手运动想象）至今仍在用。
卡尔曼滤波
xₖ = A·xₖ₋₁ + B·uₖ + wₖ
zₖ = H·xₖ + vₖ
实时脑控光标的标准解码器：状态空间方程描述运动轨迹如何映射到神经信号，卡尔曼滤波递归估计运动状态。BrainGate临床试验的核心算法之一。
互信息 / 解码比特率
I(S;R) = H(S) - H(S|R)
BCI系统性能的终极度量：从神经信号R中能提取关于意图S的信息量（比特/秒）。侵入式高密度阵列可达数十bit/s，非侵入式EEG通常仅个位数bit/s。
HH模型 · 神经元动力学
C·dV/dt = I - I_Na - I_K - I_L
Hodgkin-Huxley方程——描述神经元膜电位V如何由钠、钾等离子通道电流产生动作电位。BCI电极采集的正是这层膜电位的集体放电。

09 / Outlook

趋势展望

2026

临床验证加速期

Neuralink 21名植入者、Synchron多中心试验、中国侵入式临床首发——2026年是BCI从实验室走向临床证据积累的关键一年。手术机器人自动化（R1）降低植入门槛。

2027

AI × BCI 融合拐点

大模型时代的神经解码从线性模型迈入深度学习范式。Transfomer架构的神经信号解码器、LLM辅助的语言解码，将把意念打字速率从每分钟数十字符提升至上百字符。

2028

消费级非侵入式爆发

柔性干电极、水凝胶材料、轻量化算法三件套成熟，非侵入式BCI从医疗扩展到消费电子：脑机耳机、专注力头环、情绪监测可穿戴设备进入大众市场。

2030

中国目标：世界领先

《新一代人工智能发展规划》明确脑机接口为未来产业，目标2030年达到世界领先水平。中美双极格局成型，非侵入式中国并跑、侵入式美国领跑的差异化竞争。

2030+

双向闭环与感官重建

从单向"读脑"走向双向"读写"：视觉皮层刺激恢复光明（Blindsight路线）、听觉皮层重建、海马体记忆增强。BCI从运动辅助升级为感觉-运动闭环重建。
